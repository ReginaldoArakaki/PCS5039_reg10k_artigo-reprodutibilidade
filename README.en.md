# Reg10k — research reproducibility package

Companion repository for the study of Reg10k's architectural evolution from
isolated local automation to a connected, multi-room Digital Twin with local
behavioral analytics.

The package pins eight Git milestones, extracts static evidence, summarizes the
execution catalog, computes normalized exploratory correlations, and generates
article-ready tables. Results describe a deterministic educational testbed;
they do not claim population-level evidence from real households.

See [`README.md`](README.md) for reproduction commands and
[`CITATION.cff`](CITATION.cff) for citation metadata.
